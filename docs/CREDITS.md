# Credits and project history

## Thank you, Eric and the Spectacle contributors

[Spectacle](https://github.com/eczarny/spectacle), created by **Eric Czarny** and
built with its contributors, gave Mac users a simple, memorable way to arrange
windows from the keyboard. Xpectacle exists because that experience mattered to
a longtime user who wanted to keep using it.

Spectacle's repository is archived. Xpectacle carries its spirit forward as a
maintained Swift/SwiftUI implementation, with native Apple Silicon and Intel
builds. The original Objective-C source and history remain here for reference,
along with the original copyright and [MIT license](../LICENSE.md).

**Xpectacle is independent. It is not affiliated with or endorsed by Eric Czarny
or the original Spectacle project.** It is not an official Spectacle update, and
the original author has no obligation to maintain, support, or promote it.

The currently published 2.0.2 app retains Spectacle's app icon. That artwork is
inherited material, not an original Xpectacle identity. The [website](https://xpectacle.wonkytonks.chatgpt.site) and launch artwork now use
a separate Xpectacle identity: lavender glasses with an X-shaped bridge, ivory
keycaps, and paired windows.
This generated brand artwork was approved by Diego; it is an illustration, not an
app screenshot. The new native app icon has not yet shipped.

## The continuation

Diego began Xpectacle to preserve a familiar daily workflow and share it freely.
Claude and ChatGPT assisted with development. They are development tools, not
services required by the installed app. Source review, testing, release decisions,
and maintenance remain the project's responsibility.

The goal is to pay useful open-source work forward. Reports, fixes, documentation,
and compatibility testing are welcome through [Contributing](../CONTRIBUTING.md).

## Open-source building blocks

- **Spectacle**, by Eric Czarny and contributors — original project, interaction

- **[KeyboardShortcuts](https://github.com/sindresorhus/KeyboardShortcuts)**, by

See the source and dependency notices for the full license terms. Historical
Spectacle dependencies belong to the retained legacy project; the maintained
Swift app's external runtime package is KeyboardShortcuts.
